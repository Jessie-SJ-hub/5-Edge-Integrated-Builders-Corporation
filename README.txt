HOW TO PREVIEW THE WEBSITE
--------------------------
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The website should open in your browser.

HOW TO EDIT THE WEBSITE
-----------------------
1. Right-click index.html and choose Open with > Notepad.
2. Edit the text or section you want to change.
3. Save the file.
4. Refresh the browser to see the changes.

Use the same process for styles.css and script.js.
Keep all three files in the same main folder.
Do not rename the assets folder or move the images unless
you also update their paths in the code.

IMPORTANT BEFORE PUBLISHING
---------------------------
1. Open script.js.
2. Find COMPANY_EMAIL.
3. Replace your-company-email@example.com with the official
   5 EDGE company email address.
4. Replace the illustrative project panels with approved
   photographs and verified project information.
5. Review all contact details and company information.

CONTACT FORM LIMITATION
-----------------------
The current contact form uses mailto. It opens the visitor's
email application and prepares an email draft. It does not
store submissions online. A database-backed form can be added
later if you want enquiries to be recorded in a web dashboard.

IMAGE AND CONTENT NOTES
-----------------------
The hero image is an AI-generated visual created for this
website concept. Check the company mark/text in the image
before publishing, since generated lettering may not exactly
match the official logo.

Service and project photographs are illustrative remote
image references. Project panels are placeholders and are
not claims that 5 EDGE completed those projects.
